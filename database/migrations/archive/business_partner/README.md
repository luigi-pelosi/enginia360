# Migrazioni storiche Business Partner

File conservati byte per byte; `SHA256SUMS` ne registra le impronte SHA-256.
Non costituiscono la procedura di nuova installazione e non vanno applicati in sequenza dopo la baseline attuale.
Le prove storiche restano esplicitamente opt-in e richiedono la rispettiva baseline precedente.
Per un database nuovo usare `database/foundation.sql`, che include il solo frammento canonico `database/masterdata_business_partner.sql`.
