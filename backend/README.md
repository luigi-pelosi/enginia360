# Backend Enginia360

API ASP.NET Core .NET 10, organizzata in moduli e namespace di dominio. Documentazione generale: [Foundation](../docs/foundation.md). Specifiche di dominio: [Business Partner](../docs/masterdata_business_partner.md), [TaxManagement](../docs/taxmanagement.md).

Il backend non crea né migra lo schema all'avvio. `database/foundation.sql` è la baseline **solo per nuove installazioni**, mai da applicare al database esistente. Bootstrap, import geografico e verifiche sono descritti nella Foundation.
